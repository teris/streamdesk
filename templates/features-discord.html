Den Token im Developer Portal unter Bot → Reset Token erzeugen. Er wird verschlüsselt gespeichert und nach dem Speichern ausgeblendet.

Nach dem Verbinden kannst du Discord unter Chat & Widget auswählen. Der Chat bleibt beim Ausschalten des Expertenmodus nutzbar.

Discord-Bot einrichten

Du benötigst einen Discord-Server, auf dem du Apps hinzufügen darfst. StreamDesk übernimmt den Betrieb des Bots.

  1. App anlegen

    Öffne das Discord Developer Portal ↗, wähle New Application und vergib einen Namen.

  2. Token und Nachrichtentexte freigeben

    Unter Bot → Reset Token erzeugst du den Bot-Token. Aktiviere unter Privileged Gateway Intents den Message Content Intent und speichere. So erhält StreamDesk auch den Text normaler Kanalnachrichten.

  3. Bot auf deinen Server einladen

    Unter Installation aktiviere Guild Install. Wähle Discord Provided Link und unter den Installations-Einstellungen den Scope bot mit View Channels, Read Message History und Send Messages. Öffne den Installationslink und wähle deinen Server.

  4. Kanal-ID kopieren

    In Discord unter Benutzereinstellungen → Erweitert den Entwicklermodus einschalten. Rechtsklick auf den gewünschten Textkanal → Kanal-ID kopieren. Die Bot-Rolle muss die drei Rechte auch in diesem Kanal besitzen.

  5. In StreamDesk einbinden

    Kanal-ID und Bot-Token im Formular eintragen und Discord verbinden wählen. Danach Chat & Widget öffnen und Discord als Chat auswählen.

Verbindung klappt nicht?
  • Kanal nicht gefunden: Kanal-ID, Servereinladung und Kanalrechte prüfen.
  • Nachrichten ohne Text: Message Content Intent im Developer Portal prüfen. Für verifizierte Apps kann eine Freigabe durch Discord erforderlich sein.
  • Token ungültig: Unter Bot → Reset Token neu erzeugen und hier erneut speichern.
  • Bot wird als offline angezeigt: StreamDesk nutzt die Discord-HTTP-API. Eine grüne Online-Anzeige ist dafür nicht erforderlich.
